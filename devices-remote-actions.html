Remote actions

Do things to the device: shell, live screen and instant commands.

4

The shell is a remote terminal into the device for deep diagnosis — battery dumps, package lists, power whitelists — with no site visit. Commands run with the agent’s privileges, so treat access as sensitive.

What it doesRemote command-line into the device for diagnostics — no site visit.
dumpsys battery | grep level
pm list packages | grep fieldx
Where to find itDevices → select → Device Shell

Screen view streams the live device screen and forwards taps, swipes and typing as if you held the unit. Unattended access skips on-device acceptance — the feature that makes kiosk and headless fleets supportable.

What it doesWatch and control the live screen — tap, swipe and type as if holding the device, with unattended access for kiosks.
Where to find itDevices → select → Screen View

Actions are immediate commands executed over the persistent channel — there is no polling delay. Pending marks commands not yet executed. The list spans information, messaging, power, security and maintenance.

What it doesPick an action on the left and run it on this device. The Pending badge marks actions not yet executed.
ActionEffect
Refresh Device informationPulls the latest parameters from the unit
Send MessageShows a custom message on the device screen
Ring / Buzz DevicePlays sound to locate a nearby unit
Reboot DeviceRestarts the device remotely
Unlock DeviceReleases the screen lock
Lock DeviceApplies the screen lock immediately
Set Device Lease ExpirySets the rental/lease end date for the unit
Clear Failed Downloads QueueDrops stuck app/OTA downloads so they retry cleanly
Trigger Collect LogsPulls diagnostic logs from the device
Uninstall an AppRemoves the specified package from the device
Change Device PasscodeSets a new lock-screen passcode remotely
Perform Factory ResetWipes the device to factory state — irreversible
Remove EMM ControlsUnenrolls the device from management
Send Shell CommandRuns a shell command on the device
Where to find itDevices → select → Action

Send Action delivers over the data channel; Generate SMS Text compiles the same command as an encrypted text for dead zones, basements and roaming units. Control without data is a FieldX signature.

What it doesDescribe the command in the Description box, add a Parameter, then Send Action over data — or Generate SMS Text to deliver it as an encrypted SMS when the device is offline.
