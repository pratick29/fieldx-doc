Monitor

Observe-only views: location trails, logs and the effective policy set.

3

Location trails replay where a device has been between two dates. Trails render on map or satellite views with a GPS point list beside them — exportable for records and SLA proof.

What it doesPlots GPS history between a Start and End date on a Map/Satellite view with a GPS Locations side panel.
Pick Start Date → End Date → Submit.
Toggle Plot All on Map; Export CSV for records; page with Rows selector.
Where to find itDevices → select → Locations

Logs are the timestamped diary of device and agent events. Filter by type, search the text, refresh for the latest entries — the first stop for “what happened at 2am?” questions.

What it doesTime-stamped log messages with Search, Type filter (e.g. All Logs) and refresh.
Where to find itDevices → select → Logs

Applied restrictions show the effective policy set on this exact unit: type, value and source policy name. When a device behaves unexpectedly, this table names the responsible rule.

What it doesSearchable table of effective restrictions: Restriction Type, Value, Restriction Name. Use it to confirm a policy reached the unit.
Where to find itDevices → select → Applied Restrictions
