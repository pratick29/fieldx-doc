CORE CONCEPT

Managing restrictions

Create, configure, assign, and remove restriction policies from the FieldX Web Portal.

What it isThe default restriction of order one, created by the system. It applies to all devices, cannot be deleted, but can be edited by authorized users.
Use it forThe common set for every device — e.g. disable factory reset, enable auto date & time. Anything group-specific overrides it by higher order.

Example: globally disable debugging for all devices, then add a higher-order restriction enabling it for one group — that group gets debugging, the rest do not.

1. Side menu → Restrictions → Add at the top of the page.
2. Restriction Name — user-friendly, describing its purpose or group.
3. Order — unique number; lower orders are overridden by higher ones.
4. Group Selection — one or multiple groups from the dropdown.
5. Pick a category and configure each restriction (dropdown or text entry per its description).
6. Add (top-right) to save.
Read firstDeleting removes the restriction from the portal but does NOT undo settings already on devices. To lift settings, edit first and set everything to ‘Do not Apply’.
Side menu → Restrictions → pick the restriction → Delete → confirm (irreversible).
The Global Restriction cannot be deleted — only edited.

Deletions are logged in user audit records, so admins can see who removed what.

ADVANCED

App Watchdog

Monitor critical applications and automatically attempt to restart monitored services or activities when they stop unexpectedly.

ModeBehavior
ServiceContinuously monitors and maintains the background running status of the specified Android service.
Top ActivityKeeps the specified Activity in the foreground and relaunches it if focus changes.
PackageEnsures the entire package remains active and launches its primary launcher Activity if terminated.
PrerequisiteWatchdog works only if FieldX is installed as a system app. On capable devices, contact support for know-how.
1. Restrictions page → add or edit the restriction.
2. App Restrictions category → scroll to App Watchdog settings → Add/Update.
3. Enter each app's fully qualified class name (wrong names fail silently) → Submit.
4. Save Changes on top to apply everything.
