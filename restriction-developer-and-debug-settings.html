RESTRICTION CATEGORY

Developer & Debug Settings

A single switch for ADB and debugging features. Off everywhere by baseline, on only for engineering groups.

1
What it doesControls whether the user can enable or access debugging features such as ADB.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Where to find itRestrictions / Developer & Debug Settings / Debugging Features (ADB)

When should I use this? Use this to close off ADB access on production devices, and grant it selectively to developer groups via a higher-priority override.
