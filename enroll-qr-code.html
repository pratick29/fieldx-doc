ENROLMENT METHOD

FieldX EMM / QR Enrolment

Enrol a supported Android device directly from its initial setup screen using the FieldX system QR code.

12
Confirm with your device provider that QR code provisioning is supported.
For a low-resolution camera, use the Simplified QR Code shown at the bottom of the enrolment page.
1. Unbox and power on the device.
2. Wait for the initial Welcome screen.
3. Tap the same location on the Welcome screen 6 times quickly.
Position the device to scan the unique system enrolment QR code provided by your IT administrator.

When the setup wizard asks for network configuration, use the following values:

SettingValue
MeteredDetect automatically
ProxyNone
IP SettingsStatic
IP AddressStatic IP on the same subnet as the router
GatewayYour local router/default gateway
Network Prefix Length24
DNS 134.226.155.149
DNS 234.226.155.149
PrivacyUse randomized MAC
Send device name to networkOn (Recommended)

Choose a static IP that is on the same subnet as your router and is not already being used by another device.

Example: If the current IP is 192.168.1.100 and the gateway is 192.168.1.1, a possible static IP is 192.168.1.101, provided it is unused.

After entering the network details, select Connect and wait until Wi-Fi shows Connected.

1. The setup wizard downloads the FieldX Manager App.
2. Follow the remaining Android setup prompts.
3. Grant the requested permissions to the Manager App.
4. Select Done when the “You're all set!” screen appears.
Device runs Android 8.0 or higher and is Android Enterprise ready.
Fresh out of the box (no accounts) or factory reset — back up data first, reset wipes it.
1. Login to the FieldX Web Portal → Downloads page → QR Code Provisioning tab.
2. If the code will not scan, use the Simplified QR Code just below it.
1. Accept & Continue → follow setup → grant the Manager app its permissions.
2. If Google Protect warns during install, choose Install Anyway.
3. The device appears under New Devices — tag it and move it to its zone.
4. Next: apply Restrictions and push Apps to it.
1. Scan the Simplified QR Code shown on the FieldX enrolment page.
2. Wait for the FieldX Manager App to download and install.
3. The Manager App asks you to scan an Activation QR Code or enter an Access Code.
4. Open Activation QR Code in the FieldX Admin Portal.
5. Use the corresponding activation details to register the device.

Open Enrol Devices → Activation QR Code in the FieldX Admin Portal.

2. Select Enrol Device.
3. Scan the Activation QR Code or enter the Access Code manually.
4. Complete the enrolment steps shown on the device.
