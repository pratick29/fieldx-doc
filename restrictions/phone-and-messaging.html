RESTRICTION CATEGORY

Phone & Messaging

Two switches: outgoing calls and SMS, each Allow or Disallow. Silent fleets like signage and kiosks turn both off.

2
What it doesControls whether the user can make outgoing phone calls. Incoming and emergency calls remain available regardless of this setting.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Phone & Messaging / Allow Outgoing Calls

When should I use this? Use this on devices that should only receive calls, such as dedicated support-line handsets.

What it doesControls whether the user can send or receive SMS messages.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Phone & Messaging / Allow SMS

When should I use this? Use this where SMS is not part of the intended use case for the device.
