Web Content Filter

Block specific domains and IP addresses at the device level. Requires the Net Blocker app, available from Downloads → Plugins in the Web Portal.

2
What it doesSets the URL of a hosts file listing domains and IPs to block on the device, in standard Linux hosts-file format.
What to enterEnter the HTTPS URL of the hosts file.
Available forNot specified in the FieldX source.
Where to find itRestrictions / Web Content Filter / Hosts File Link

When should I use this? Use this to apply a maintained, external blocklist across your device fleet.

What it doesBlocks specific domains and IP addresses in addition to whatever the Hosts File Link provides.
What to enterEnter a comma-separated list of domains and/or IP addresses to block.
Available forNot specified in the FieldX source.
Where to find itRestrictions / Web Content Filter / Blacklist Specific Domains

When should I use this? Use this to add one-off blocks on top of your main hosts-file blocklist.
