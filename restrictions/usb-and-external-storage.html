USB & External Storage

Physical exfiltration controls: mounting media, file transfer, and USB settings changes. Block all but charging for secure sites.

3
What it doesControls whether external media, such as SD cards and USB thumb drives, can be mounted.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Minimum Android API levelLollipop 5.0 (21)
Where to find itRestrictions / USB & External Storage / Mount Physical Media

When should I use this? Use this to prevent data being introduced to or extracted from the device via removable media.
