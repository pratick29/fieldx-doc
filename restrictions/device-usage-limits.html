Device Usage Limits

Daily app limits, a hard device cut-off time, and total screen-time caps that hold until 4 AM. Built for shared and kids devices.

3
What it doesSets daily usage limits for individual apps, to manage screen time more effectively.

Configured through its own settings window in the FieldX console rather than a simple Allow/Disallow toggle.

Available forFieldX EMM
Where to find itRestrictions / Device Usage Limits / Apps Daily Usage Limits

When should I use this? Use this to cap time spent in specific apps, such as games or social media, on managed devices.

What it doesSets a daily time after which the device cannot be used, except for designated emergency apps, which remain available throughout.
What to enterEnter the daily cut-off time.
Available forFieldX EMM
Where to find itRestrictions / Device Usage Limits / Daily Device Cut-off Time

When should I use this? Use this to enforce device-free hours, for example overnight on employee- or student-assigned devices.

What it doesSets a total daily screen-time budget. Once the limit is reached, apps are disabled and automatically re-enabled at 4:00 AM, when the daily tracking window resets.
What to enterEnter the maximum number of screen-time hours allowed per day.
Available forFieldX EMM
Where to find itRestrictions / Device Usage Limits / Total Screen Time for the day (in Hours)

When should I use this? Use this to enforce an overall daily usage cap rather than limiting individual apps.

Important notes

Note: Screen time is tracked from 4:00 AM to 3:59 AM the following day.
