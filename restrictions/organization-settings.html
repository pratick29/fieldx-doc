RESTRICTION CATEGORY

Organization Settings

Your organization’s name and support messages surface on lock screens, alert dialogs and admin screens. Branding plus a help path.

3
What it doesSets the organization name shown on the lock screen (e.g. "This device is managed by ABC").
What to enterEnter the organization name to display.
Available forNot specified in the FieldX source.
Where to find itRestrictions / Organization Settings / Organization Name

When should I use this? Use this so users and finders of a device can identify the managing organization at a glance.

What it doesSets the organization support message shown in the alert dialog presented to the user.
What to enterEnter the short support message to display.
Available forNot specified in the FieldX source.
Where to find itRestrictions / Organization Settings / Organization Support Message

When should I use this? Use this to give users a quick pointer to IT support when a managed action affects them.

What it doesSets the longer support message displayed to the user on the device administrators settings screen.
What to enterEnter the extended support message to display.
Available forNot specified in the FieldX source.
Where to find itRestrictions / Organization Settings / Organization Long Support Message

When should I use this? Use this to provide fuller support instructions than the short message allows.

Important notes

Note: Messages longer than 20,000 characters may be truncated.
