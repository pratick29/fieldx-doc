Bluetooth Connectivity

Decide whether Bluetooth exists, its default state, whether users may toggle it, and whether sharing is allowed. Pairing-heavy fleets lock this down first.

4
What it doesControls whether Bluetooth is available on the device at all.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Bluetooth Connectivity / Allow Bluetooth

When should I use this? Use this to close off Bluetooth entirely as a data-exfiltration or pairing risk.

What it doesSets whether Bluetooth is turned on or off by default.
OptionWhat it does
OnTurns the controlled feature on.
OffTurns the controlled feature off.
Available forFieldX EMM, Samsung & FieldX EMM, Android Enterprise
Where to find itRestrictions / Bluetooth Connectivity / Default Bluetooth State

When should I use this? Use this to set a baseline Bluetooth state without necessarily preventing the user from changing it — pair with "Let users Toggle Bluetooth" for that.

What it doesControls whether outgoing Bluetooth sharing is prevented on the device.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Where to find itRestrictions / Bluetooth Connectivity / Bluetooth Sharing

When should I use this? Use this to allow Bluetooth connectivity (for accessories, etc.) while blocking file sharing over Bluetooth.

What it doesControls whether the user can change the Bluetooth on/off state themselves.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Bluetooth Connectivity / Let users Toggle Bluetooth

When should I use this? Use this together with Default Bluetooth State to lock Bluetooth to a fixed state the user cannot override.
