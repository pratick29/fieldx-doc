RESTRICTION CATEGORY

App Installation & Permissions

Controls where applications may be installed from, and which apps automatically receive runtime permissions. Note that the three "install source" restrictions below overlap in scope — see the note at the end of this section on how they differ.

4
What it doesControls whether the user can install apps from any source at all, including the Play Store.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / App Installation & Permissions / Disallow App Installs from all Sources

When should I use this? Use this for the strictest lockdown, when devices should never gain new apps through user action — for example, single-purpose kiosk hardware.

Important notes

Note: The FieldX source describes this restriction only as "controls whether the user is allowed to install from all apps," which reads as a typo. The scope above ("any source at all") is inferred from the restriction's name and its position as the broadest of the three install-source restrictions in this section — confirm against your FieldX console before relying on it.

What it doesControls whether the user can enable the "Unknown Sources" setting that permits installing apps from outside the Play Store. adb and trusted app stores are not affected by this setting.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / App Installation & Permissions / Disallow App Installs from Sources except Google Play Store, adb & MDM

When should I use this? Use this when devices should only receive apps from the Play Store, adb, or MDM push, while still allowing normal Play Store use.

What it doesDisables installs from every unknown source — including adb, third-party app stores, and the Downloads folder — leaving only MDM-pushed installs available.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / App Installation & Permissions / Disallow App Installs Unknown Sources Globally (except MDM)

When should I use this? Use this when even adb-based installs are a risk you want to close off, and MDM push should be the only install path.

Important notes

Note: This is the narrowest of the three install-source restrictions: it blocks adb as well, which the "except Google Play Store, adb & MDM" restriction above does not.

What it doesApps listed here automatically receive all their requested runtime permissions (Location, Storage, Microphone, Camera, Read SMS, etc.) without prompting the user.
What to enterEnter the package name(s) of the application(s) that should receive automatic runtime permissions.
Available forFieldX EMM
Where to find itRestrictions / App Installation & Permissions / Auto Grant Runtime Permissions to Apps

When should I use this? Use this for trusted line-of-business apps where a permission prompt would block unattended or kiosk-style operation.
