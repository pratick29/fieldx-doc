RESTRICTION CATEGORY

Device Settings Override

Override low-level device settings directly. These are powerful controls — test thoroughly before wide deployment, since incorrect values can cause unwanted device behavior, and not all changes apply immediately (some require a reboot).

3
What it doesDirectly sets values in Android's System Settings namespace (equivalent to Settings.System). This works only on devices provisioned with the PLATFORM installation type.

Configured through its own settings window in the FieldX console rather than a simple Allow/Disallow toggle.

Available forNot specified in the FieldX source.
Where to find itRestrictions / Device Settings Override / System Settings

When should I use this? Use this only for specific, documented System-namespace keys you need to override — consult the FieldX knowledge base for the constants list before changing anything here.

Important notes

Note: Requires PLATFORM installation type. Applying an unsupported or malformed value can cause unexpected device behavior.
