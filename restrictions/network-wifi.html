RESTRICTION CATEGORY

Network - WiFi

Lock access-point changes, enforce Wi-Fi on or off, and preload corporate SSIDs for managed networks.

3
What it doesControls whether the user can change Wi-Fi access point configuration.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Minimum Android API levelJelly Bean 4.3 (18)
Where to find itRestrictions / Network - WiFi / Config Wifi

When should I use this? Use this to keep devices on an approved set of Wi-Fi networks.

What it doesForces Wi-Fi on or off by default; the user cannot toggle it themselves.
OptionWhat it does
OnTurns the controlled feature on.
OffTurns the controlled feature off.
Available forFieldX EMM
Where to find itRestrictions / Network - WiFi / Enforce WiFi Status

When should I use this? Use this to guarantee devices always stay connected (On) or to force cellular-only operation (Off).

What it doesAdds or updates Wi-Fi SSIDs on the device. This only adds or updates system Wi-Fi settings — it never deletes an existing SSID. Only WPA and open (NONE) security are supported.
What to enterUse the Wi-Fi configuration window in FieldX, or enter values in the format: wpa,true,ssid,password | none,true,ssid | wpa,false,ssid,password
Available forFieldX EMM
Where to find itRestrictions / Network - WiFi / Predefined WiFi SSID Config

When should I use this? Use this to pre-provision known Wi-Fi networks on managed devices without user setup.
