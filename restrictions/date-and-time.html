RESTRICTION CATEGORY

Date & Time

Control date, time, and time-zone settings. Auto Time Zone and Auto Time are separate restrictions: one governs the time zone, the other the clock itself.

4
What it doesControls whether the user is prevented from configuring date, time, and time zone.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Minimum Android API levelPie 9.0 (28)
Where to find itRestrictions / Date & Time / Config Date Time

When should I use this? Use this to keep device date, time, and time-zone settings under organizational control.

What it doesSets the time zone for the device. This only takes effect if Auto Time Zone is set to Manual.
What to enterEnter a valid time-zone identifier, e.g. Asia/Delhi or Asia/Gaza.
Available forFieldX EMM
Where to find itRestrictions / Date & Time / Set Time Zone

When should I use this? Use this to pin devices to a specific time zone regardless of their physical location.

Important notes

Note: Only takes effect when Auto Time Zone is set to Manual.

What it doesControls whether the device's time zone is set automatically or manually.
OptionWhat it does
AutoThe device sets its time zone automatically; the user cannot change it manually.
ManualThe time zone is set manually, using the Set Time Zone restriction above.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Date & Time / Auto Time Zone

When should I use this? Use Manual together with Set Time Zone to pin a fixed time zone; use Auto to let the device follow network/location time zone data.

What it doesControls whether the device's system clock is set automatically or manually.
OptionWhat it does
AutoThe device sets its system time automatically; the user cannot change it manually.
ManualThe system time can be set manually.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Date & Time / Auto Time

When should I use this? Use Auto to guarantee devices always show accurate network time, which also matters for certificate and token validation.
