Enroll Device

Set up and enrol an Android device with FieldX using QR code, Web Installer, or the FieldX Installer app.

Android Step-by-step guide FieldX EMM
Before you begin Choose the enrolment method supported by your device. Some methods require a new or factory-reset device, while others require USB or wireless debugging.

GETTING STARTED

Choose an enrolment method

Use the method that matches your Android device and available setup options.

ENROLMENT METHOD

FieldX EMM / QR Enrolment

Enrol a supported Android device directly from its initial setup screen using the FieldX system QR code.

QR provisioning
FieldX Android enrolment
Confirm with your device provider that QR code provisioning is supported.
For a low-resolution camera, use the Simplified QR Code shown at the bottom of the enrolment page.
1. Unbox and power on the device.
2. Wait for the initial Welcome screen.
3. Tap the same location on the Welcome screen 6 times quickly.
Position the device to scan the unique system enrolment QR code provided by your IT administrator.

When the setup wizard asks for network configuration, use the following values:

SettingValue
MeteredDetect automatically

IP SettingsStatic
IP AddressStatic IP on the same subnet as the router
GatewayYour local router/default gateway

Send device name to networkOn (Recommended)

Choose a static IP that is on the same subnet as your router and is not already being used by another device.

Example: If the current IP is 192.168.1.100 and the gateway is 192.168.1.1, a possible static IP is 192.168.1.101, provided it is unused.

After entering the network details, select Connect and wait until Wi-Fi shows Connected.

1. The setup wizard downloads the FieldX Manager App.
2. Follow the remaining Android setup prompts.
3. Grant the requested permissions to the Manager App.
4. Select Done when the “You're all set!” screen appears.
ENROLMENT METHOD

Simplified QR Code

Use the simplified QR flow when your device camera cannot reliably scan the standard enrolment QR code.

Alternative QR
1. Scan the Simplified QR Code shown on the FieldX enrolment page.
2. Wait for the FieldX Manager App to download and install.
3. The Manager App asks you to scan an Activation QR Code or enter an Access Code.
4. Open Activation QR Code in the FieldX Admin Portal.
5. Use the corresponding activation details to register the device.
ENROLMENT METHOD

Web Based Enrolment

Use Web Installer for Android devices that do not support Zero-Touch or QR-code based enrolment.

USB
Android device that is new or factory-reset.
USB cable.
Recommended: Linux or Mac with the latest Chrome browser.
Windows may require additional device drivers depending on the phone model.
1. Unbox a new device or factory reset an existing device.
2. Power on the device.
3. Complete the Android Setup Wizard.
4. Do not add a Google account.
5. Do not install third-party apps or perform extra setup.
1. Open Settings → About phone.
2. Tap Build number 7 times.
3. Open Developer options.
4. Turn on USB debugging and confirm the warning.

Close Android Studio and other tools that use ADB before starting the Web Installer. The Web Installer needs exclusive access to the device.

If an ADB server is running, stop it with adb kill-server.
1. Connect the Android device to your computer using USB.
2. Connect the device to Wi-Fi.
3. In Web Installer, select Connect your Device.
4. Follow the on-screen provisioning steps.
5. Wait while the FieldX EMM agent is installed and the device is provisioned.

On the Android device, confirm that the FieldX EMM app/agent is installed.

In the FieldX Admin Portal, confirm that the device appears as enrolled and that the required policies and profiles are applied.

ENROLMENT METHOD

App Based Enrolment

Use the FieldX Installer app to enrol a target Android device from another Android phone over wireless ADB.

Wireless ADB
FieldX Installer workflow
Both phones must be connected to the same Wi-Fi network.
The target device should be new or freshly factory-reset.
The target device should have no Google/user accounts or other device-management app.
Wireless debugging must be enabled on the target device.
The installer phone needs a FieldX account.
The target device should be Android 14 or above.
1. Complete the Android setup wizard without signing in to a Google or other account.
2. Open Settings → About phone.
3. Tap Build number 7 times to enable Developer options.
4. Open Settings → System → Developer options.
5. Enable Wireless debugging.
6. Keep the Wireless debugging screen open while pairing.
1. Open FieldX Installer on the installer phone.
2. Enter your FieldX email and password.
3. Tap Sign in.

The session may be restored automatically on future launches.

QR pairing

1. On the target: Settings → Developer options → Wireless debugging → Pair device with QR code.
2. On the installer phone, tap Show pairing QR.
3. Scan the QR shown on the installer phone using the target device.

Pairing code

1. On the target, choose Pair device with pairing code.
2. On the installer phone, tap Scan for devices.
3. Select the target or enter its IP and pairing port.
4. Enter the 6-digit pairing code and tap Pair.
Important: The pairing port and connect port are different. Do not use the pairing port as the connect port.

Auto-discover: Select Scan for devices, choose the target, then select Connect when the connection port is available.

Manual: Enter the target IP address and the ADB connect port shown under Wireless debugging → IP address & port, then select Connect.

When the state shows Connected, select Continue to Provision.

1. Select Start setup.
2. Wait while provisioning runs.
3. Do not disconnect the device or close FieldX Installer.
4. When complete, the app displays “All done! FieldX is installed and this device is ready to use.”
5. Select Disconnect and check the target device.
ENROLMENT SUPPORT

Activation QR Code

Activation details are used with Simplified QR Code, Web Installer, and manual installation methods.

Activation

Open Enrol Devices → Activation QR Code in the FieldX Admin Portal.

The page provides the information required to register a device, including:

Organization Code
Access Code
Activation QR Code
1. Open the FieldX Android application.
2. Select Enrol Device.
3. Scan the Activation QR Code or enter the Access Code manually.
4. Complete the enrolment steps shown on the device.

The Server URL field is required only when connecting to a privately hosted MDM server.

HELP

Troubleshooting

Common issues during device enrolment and the steps to resolve them.

Confirm USB debugging is enabled.
Try another USB cable or USB port.
On Windows, make sure the correct device drivers are installed.
Close Android Studio and other ADB tools.
If required, run adb kill-server, reconnect the device, and retry.
Make sure both phones are connected to the same Wi-Fi network.
Confirm Wireless debugging is enabled on the target device.
For pairing-code mode, keep the target's pairing screen open.
Return to the Connect step.
Reconnect the target device.
Return to Set up device.
Select Start setup again.
Make sure the target device has no signed-in accounts.
Make sure no other device-management app is installed.
If necessary, factory reset the device and repeat the preparation steps.
