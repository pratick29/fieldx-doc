RESTRICTION CATEGORY

Kiosk Policies

Restrict the device to load only the required apps in Kiosk mode. To use these settings, push the Kiosk Plugin App to devices from the Downloads section of the Web Portal.

3
What it doesConfigures Kiosk Mode: which apps are permitted, and which Settings icons (if any) remain visible to the user.
What to enterUse the Kiosk configuration window in FieldX. Package names must be valid apps already installed on the device or pushed from the platform.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Kiosk Policies / Kiosk Mode Settings

When should I use this? Use this to lock a device into a single-purpose, restricted-app kiosk experience.

What it doesSets the password required to exit Kiosk Mode, provided as an MD5 hash.
What to enterEnter an MD5 hash of the password (case-sensitive, no length restriction). Hashes can be generated at md5hashgenerator.com.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Kiosk Policies / Kiosk Admin Password

When should I use this? Use this to make sure only authorized staff can exit Kiosk Mode.

What it doesRestricts the device to displaying a single URL. Exiting the browser requires entering a PIN.
What to enterEnter the URL to lock the device to.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Kiosk Policies / Kiosk Browse Url

When should I use this? Use this for single-purpose web kiosks, such as a check-in screen or a public information display.
