RESTRICTION CATEGORY

App Management & Control

Controls app installation, uninstallation, visibility, and what happens to apps that fall outside an approved list.

9
What it doesControls whether the user can uninstall applications from the device.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / App Management & Control / Allow user to uninstall apps

When should I use this? Use this to stop end users from removing required line-of-business or security apps.

What it doesControls whether the user can modify installed applications' data through Settings or the launcher, such as clearing cache or storage.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Allow user to clear App Cache and Storage

When should I use this? Use this when clearing app data could disrupt a workflow that depends on cached or local app state.

What it doesHides the listed apps on the device without uninstalling them. Removing an app from this list does not re-enable it — it must be explicitly added to the Whitelist.
What to enterEnter the package name(s) of the application(s) to hide.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Blacklist Apps

When should I use this? Use this to hide distracting or non-business apps (games, social media) without removing them from the device.

What it doesReverses a previous Blacklist entry for the listed apps. This restriction only undoes blacklisting — it has no other effect.
What to enterEnter the package name(s) of the application(s) to re-enable.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Whitelist Apps

When should I use this? Use this to restore visibility of an app that was previously hidden by the Blacklist Apps restriction.

What it doesPrevents the user from uninstalling the listed apps.
What to enterEnter the package name(s) of the application(s) to protect from uninstall.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Disable Apps from Uninstall

When should I use this? Use this to protect specific required apps from removal without blocking uninstalls device-wide.

What it doesReverses a previous "Disable Apps from Uninstall" entry, allowing the listed apps to be uninstalled again.
What to enterEnter the package name(s) of the application(s) to re-allow uninstalling.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Enable Apps for Uninstall

When should I use this? Use this to restore the ability to uninstall an app that was previously protected.

What it doesForce-uninstalls the listed apps if they are currently installed. If a system app is listed, it is disabled instead, since system apps cannot be uninstalled.
What to enterEnter the package name(s) of the application(s) to remove.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Uninstall Listed Apps from Device

When should I use this? Use this to clean unwanted or non-compliant apps off devices that already have them installed.

What it doesRestricts the device to only the apps on this list. Every other app — including sideloaded ones — is automatically uninstalled or disabled.
What to enterEnter the package name(s) of every application that should remain permitted on the device.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Permitted Apps Policy

When should I use this? Use this for locked-down, single-purpose deployments where only an approved app set should ever run.

Important notes

Note: This is an allowlist model: anything not listed is treated as non-permitted. Pair it with "Non-Permitted App Action" below to control what happens to those apps.

What it doesChooses how the device handles an app that isn't on the Permitted Apps Policy list.
OptionWhat it does
No ActionThe app is left alone.
Uninstall immediatelyThe app is force-uninstalled if it is a user-installed app.
Hide them from Apps listThe app is hidden from the launcher without being removed. This is the default.
Disable the AppThe app is disabled and cannot be launched.
Available forFieldX EMM
Where to find itRestrictions / App Management & Control / Non-Permitted App Action

When should I use this? Use this together with the Permitted Apps Policy to decide how strictly non-approved apps are dealt with — from a soft hide up to a hard uninstall.
