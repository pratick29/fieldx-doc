Restrictions — full reference

Restrictions are lockdown policies pushed from the console to devices. Each restriction controls one behavior — installing apps, using the camera, joining Wi-Fi — with a priority order that decides which rule wins. Policies attach to groups, so different fleets get different rules.

Read full →
Enroll Device

Enrollment is how a device joins FieldX management. Each device is enrolled once — via QR code, web installer, another phone, or activation code — after which it downloads its policies and apps automatically.

Read full →
Devices

Devices is the live inventory of every enrolled endpoint. Each device reports 100+ parameters — battery, storage, signal, location — and accepts 20+ instant actions like reboot, lock, wipe, or block. It is where daily fleet control happens.

Read full →
Groups

Groups organize devices so policies apply in bulk instead of per device. Smart groups collect devices by department, location, or tags, while buckets and zones isolate sites with their own admins. Policies attach to groups with a priority order that decides which rule wins.

Read full →
Apps

Apps management controls which applications exist on devices. Admins silently install, update, or remove apps, block distracting ones through blacklist and whitelist policies, and offer approved tools through a private store that needs no Google Play.

Read full →
Reports

Reports turn fleet data into visibility. Standard reports cover inventory, compliance, apps, OTA, and uptime, exportable as CSV, Excel, or PDF. Alerts notify admins of offline, geofence, or battery events by email, SMS, or webhook.
