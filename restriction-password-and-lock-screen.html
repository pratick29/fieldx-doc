RESTRICTION CATEGORY

Password & Lock Screen

Manage lock-screen and password requirements on the device.

6
What it doesControls whether the managed profile is allowed to share a single lock-screen challenge with the primary user, rather than requiring its own.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Minimum Android API levelPie 9.0 (28)
Where to find itRestrictions / Password & Lock Screen / Unified Password

When should I use this? Use this when the managed (work) profile should require its own separate lock-screen credential from the personal profile.

What it doesSets the number of failed lock-screen attempts allowed before the device is automatically wiped and its data deleted.
What to enterEnter the maximum number of failed attempts to allow before a wipe is triggered.
Available forFieldX EMM
Where to find itRestrictions / Password & Lock Screen / Max. Failed Password Attempts

When should I use this? Use this to protect data on lost or stolen devices — set conservatively, since this triggers a full wipe.

What it doesControls whether the user is permitted to set a Keyguard (lock screen) at all. Disallowing this removes the user's ability to set one.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Where to find itRestrictions / Password & Lock Screen / Allow Lock Screen

When should I use this? Use this only in specific shared-device or kiosk scenarios where a lock screen would get in the way of the intended use.

What it doesSets the minimum lock-screen password complexity required on the device.
OptionWhat it does
High SecurityRequires the high-security lock-screen password policy.
Medium SecurityApplies the medium-security lock-screen password policy. Recommended for most deployments.
Low SecurityApplies the low-security lock-screen password policy.
Any Password SecurityAllows any of the supported password-security levels.
Available forFieldX EMM
Where to find itRestrictions / Password & Lock Screen / Keyguard Password Security

When should I use this? Use this to enforce a minimum password strength across managed devices.

What it doesSets how long a passcode can go unchanged before the user is forced to reset it.
OptionWhat it does
10 daysThe user must reset their passcode every 10 days.
20 daysThe user must reset their passcode every 20 days.
30 daysThe user must reset their passcode every 30 days.
NeverThe passcode never expires.
Available forFieldX EMM
Where to find itRestrictions / Password & Lock Screen / Lock Screen Timeout

When should I use this? Use this to enforce periodic passcode rotation as part of a security policy.

What it doesSets device-owner information shown on the lock screen. This overrides any owner information the user set manually and prevents the user from changing it further.
What to enterEnter the message to display on the lock screen.
Available forFieldX EMM
Where to find itRestrictions / Password & Lock Screen / Lock Screen Message

When should I use this? Use this to display organization contact or ownership information for anyone who finds a lost device.
