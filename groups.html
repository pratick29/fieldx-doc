Groups

A group bundles devices with their restrictions and apps — create it, fill it manually or by rules, then attach policies once for the whole fleet slice.

Auto rulesBulk assignPriority order

PathGroups → click a group name → Group Details, Devices, Restrictions, Apps.
REFERENCE

Groups table

Every group at a glance, with per-row actions.

DefinitionA group is a logical classification of managed devices — by Department, Branch, Type of use, or Hardware characteristics (e.g. Production Devices, Beta Devices, Internal Test Users, Samsung Devices, TV Boxes). Grouping lets admins manage devices at scale.
Use casesSelectively push Apps, apply Restrictions, or push OTA firmware to one group of devices.
Groups vs ZonesGroups are for managing devices; Zones are for putting devices into different buckets.
Manual addition — pick devices and assign them.
Bulk addition — paste IMEI/Serial lists.
Automatic grouping — rules place devices themselves.
What it doesLists all groups with columns for Name, Last Updated Time, Devices, Restrictions and Apps, plus a Search box and an add (+) button.
Row actionsSend Action runs a command on the group; Delete removes it.
Where to find itGroups (top-level console page)
Group DetailsGroup Name (required), Max. Devices (leave empty for unlimited), Apply Auto Rules only to devices Reported Since (date), and Auto add only Android Enterprise Devices checkbox.
Auto Grouping RulesPick a Rule, enter a Value or Regex, then Add — matching devices join automatically. The dialog lets IT admins combine rules and cap group size per requirement.
Fill Group Name → set limits → add rules → Add.
Cancel discards everything.

Group Details tab

Edit the group, its rules, and bulk membership.

What it doesChange the Group Name, Max. Devices, Reported-Since date or AE-only flag, then Save. Delete (or the ⋮ menu) removes the group.
Rule typesManufacturer & Model (e.g. Google, Pixel 7a), Regex on IMEI, Serial or MAC address, and App package (e.g. com.android.vending groups devices with Play Store installed).
MatchingAll rules work on OR basis — a device joins if any one rule matches. Rules apply immediately to enrolled devices and are evaluated for every new device.
TipsUse Manufacturer & Model to blacklist manufacturer-bundled apps; Serial mapping for manufacturer batches; IMEI patterns for batch purchases with similar IMEIs; app matching for fleets with different preinstalled apps.
Existing rulesListed as Rule Name / Rule Value rows; add more with Rule + Value or Regex + Add.
Where to find itGroups → click a group name → Group Details
1. Open My Devices or New Devices (or the top-bar Search), select one or more devices.
2. Click Assign Group on the right side → pick the group → save.
3. From a Device Details page: search by IMEI/Serial → Device ID link → Assign Group → save.

Apps and restrictions can take 15–30 minutes to land after assignment.

What it doesPaste comma-separated IMEI or Serial numbers (pick which with the radio buttons) and Submit — to add units in bulk, or remove them in bulk.
NoteRemoving devices from a group never removes their restrictions or apps.
Choose IMEI Number or Serial Number → paste list → Submit.
Name groups technically — by model, make, manufacturer.
Auto rules trigger full workflows: grouping auto-pushes apps and restrictions.
Deleting devices from a group removes membership only — restrictions and apps stay on.
