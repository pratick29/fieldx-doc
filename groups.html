REFERENCE

Grouping constructs

Three layers for organizing a fleet of any size.

3
What it doesGroups devices by department, location, project, role, OS or custom tags for bulk actions and policy targeting.

When should I use this? Any fleet above a handful of devices — assign policies once per group instead of per device.

What it doesIsolates devices and their policies per zone (city, store, school) without affecting other zones; zone-based inventory and dashboards.

When should I use this? Multi-site deployments — franchises, districts, regional fleets.

What it doesTiered users (Super Admin → Zone Admin → Team lead), each seeing only their devices.

When should I use this? Resellers and large enterprises needing delegated administration.

CONCEPT

Assignment & priority

How policies attach to groups and which wins.

1. Restrictions → Add → name + unique Order (priority).
2. Assign to one or more Groups.
3. Higher-priority policies override lower ones for the same devices.
