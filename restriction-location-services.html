RESTRICTION CATEGORY

Location Services

Control the GPS hardware and location settings on the device. "Location State" forces the setting to a fixed value; "Allow Location Configuration" instead controls whether the user is free to change it themselves.

3
What it doesForces the device's location setting to a fixed state, overriding user control.
OptionWhat it does
Always ONLocation services are forced on at all times.
Always OFFLocation services are forced off at all times.
Available forFieldX EMM, Android Enterprise
Where to find itRestrictions / Location Services / Location State

When should I use this? Use Always ON for field-tracking or delivery use cases; use Always OFF where location tracking must be prevented.

What it doesControls whether the user can enable or disable individual location providers.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Where to find itRestrictions / Location Services / Allow Location Configuration

When should I use this? Use this when location should stay user-configurable but changes should be blocked entirely.

What it doesControls whether the user can turn on location sharing.
OptionWhat it does
AllowAllows the behavior controlled by this restriction.
DisallowPrevents the behavior controlled by this restriction.
Available forFieldX EMM
Minimum Android API levelJelly Bean 4.3 (18)
Where to find itRestrictions / Location Services / Allow Location Sharing

When should I use this? Use this to prevent a user from sharing their location with apps or contacts outside of organizational policy.
